# Airbnb France Data Analysis

## Overview

This project analyzes Airbnb listings in France to identify the key factors that drive revenue and occupancy.

The goal is to uncover actionable insights that can help hosts optimize their listings and maximize performance.

---

## Tools & Technologies

- Python (pandas)
- SQL
- Matplotlib
- Power BI

---

## Dataset

The dataset contains over 95,000 Airbnb listings across Europe, with 25,000+ listings specifically from France.

Key variables include:
- Price
- Rating
- Number of reviews
- Number of photos
- Room type
- Revenue (TTM)
- Reserved days

---

## Key Analysis

### 1. Rating vs Revenue
Listings with higher ratings generate significantly more revenue.

### 2. Reviews vs Revenue
Properties with more reviews consistently outperform others, highlighting the importance of social proof.

### 3. Photos vs Occupancy
Listings with 30–49 photos achieve the highest occupancy rates, suggesting an optimal number of images.

### 4. Room Type vs Revenue
Entire homes generate more revenue than private rooms, indicating a strong preference for full-property rentals.

---

## Key Insights

- Listings rated above 4.5 generate more than double the revenue compared to lower-rated listings  
- Social proof (reviews) plays a critical role in driving bookings  
- There is a diminishing return effect when adding too many photos  
- Entire homes outperform private rooms in terms of revenue  

---

## Conclusion

This analysis shows that both qualitative factors (ratings, reviews) and listing presentation (photos, property type) significantly impact Airbnb performance.

Hosts can leverage these insights to optimize their listings and increase profitability.
